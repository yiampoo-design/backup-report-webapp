พร้อมตั้งค่า

ปกติโปรแกรมจะ Login หน้า File Station ผ่าน Chromium และดาวน์โหลด abb_daily_result_YYYY-MM-DD.csv ของวันนี้โดยอัตโนมัติ โดยไม่เรียก NAS API หากเลือกไฟล์ด้านบน ระบบจะใช้ไฟล์ที่เลือกแทน

ภาพ Task List จาก Active Backup (ไม่บังคับ) Capture หน้าจอ แล้วกลับมาหน้านี้และกด Ctrl+V เพื่อวางภาพ

ภาพจะอยู่เหนือข้อมูล CSV ในหน้าแรก รองรับ PNG/JPEG ไม่เกิน 12 MB; หากไม่วางหรือเลือกภาพ รายงานยังสร้างได้ตามปกติ

รอบใช้งานจริงปิดเวลา 09:00 น. ค่าตารางทั้งหมดมาจาก CSV ที่เลือก ส่วน Audit และ Yard ใช้ภาพ Capture จากหน้าเว็บ DSM เท่านั้น
